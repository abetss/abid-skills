Build in-house on Postgres

We own the semantics, on infrastructure we already run.

Advantages

  • Zero new infrastructure or on-call surface
  • Full SQL for debugging and audit queries
  • Marginal cost is effectively zero at our scale

Drawbacks

  • We build and maintain the expiry sweeper ourselves
  • Peak write volume needs a load test before cutover

Buy a managed session service

Vendor owns storage, expiry, and replication.

Advantages

  • Nothing to operate — expiry and failover included
  • Fastest time to ship: SDK integration only

Drawbacks

  • Auth state leaves our infrastructure — security review required
  • Per-session pricing grows linearly with our heaviest cost driver
  • Migration path out is a rewrite, not an export
