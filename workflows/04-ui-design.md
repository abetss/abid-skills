# UI / UX Design Process Workflow

This flow focuses on conceptualizing, visualizing, and iterating on designs before full implementation.

```text
[ Feature Requirements ]
          │
          ▼
[ Design Discovery ]     <-- (Skill: design-discovery)
          │
          ▼
[ Low-Fi Wireframing ]   <-- (Skills: design-in-asci, excalidraw-diagram)
          │
          ▼
[ Props & Data Models ]  <-- (Skill: view-model-props)
          │
          ▼
[ Hi-Fi Prototyping ]    <-- (Skill: design-in-storybook)
          │
          ▼
[ Iterate & Refine ]     <-- (Skill: design-iterate)
          │
          ▼
[ Finalize UI Handoff ]
```
