# Debug Workflow

From a bug report all the way to a captured fix.

Entry point: the `debugging` skill (which loads sub-files as needed).

## Happy Path

```
┌─────────────────────────┐
│        bug found        │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│       never-again       │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│ troubleshooting-writer  │
└─────────────────────────┘
```

## Triage Branches (chosen inside `debugging`)

### Trivial — root cause obvious, one-line fix

```
┌─────────────────────────┐
│        bug found        │
└────────────┬────────────┘
             │   (skip diagnose)
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

### Standard — root cause unclear but localized

```
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

### Complex — multi-component, intermittent, architectural

```
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│    defense-in-depth     │
└─────────────────────────┘
```

### Production incident — critical, user-facing

```
┌─────────────────────────┐
│        mitigate         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

## Sub-routines (loaded by `debugging` when needed)

### Flaky test — timing issue

```
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│ condition-based-waiting │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

### Test pollution — one test breaks another

```
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│      find-polluter      │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

### Stuck after 3+ attempts

```
┌─────────────────────────┐
│        diagnose         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│        escalate         │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│           fix           │
└─────────────────────────┘
```

## After the Fix

```
┌─────────────────────────┐
│           fix           │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│       never-again       │   ← fix the process that allowed it
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│ troubleshooting-writer  │   ← document the fix in the KB
└─────────────────────────┘
```
