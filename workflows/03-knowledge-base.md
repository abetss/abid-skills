# Knowledge Base (KB) Documentation Workflow

This flow shows how system knowledge, team conventions, and standard procedures are extracted, documented, and maintained.

```text
       [ Identify Knowledge Gap / Pattern ]
                       │
                       ▼
    ┌──────────────────┼──────────────────┐
    │                  │                  │
    ▼                  ▼                  ▼
[ SOPs ]        [ Conventions ]    [ Product Guides ]
(sop-writer)  (conventions-writer) (product-guide-writer)
    │                  │                  │
    └──────────────────┼──────────────────┘
                       ▼
       [ Review Guides / Troubleshooting ]
(write-review-guide)       (troubleshooting-writer)
                       │
                       ▼
              [ Publish to KB ]
                       │
                       ▼
              [ Team Review ]     <-- (Skill: grill-me for intense QA of knowledge)
```
