# Feature Development Workflow

This flow covers the end-to-end process of building a new feature, transitioning from initial product requirements to final execution.

```text
[ Write Requirements ]
         │
         ▼
[ Design Discovery ]     <-- (Skill: design-discovery)
         │
         ▼
[ Plan Prep ]    <-- (Skill: plan-prep)
         │
         ▼
[ Architecture Solutions]<-- (Skill: architect-solution)
         │  ↳ (Skill: review-db-schema)
         ▼
[ Plan Implementation ]
         │
         ▼
[ Execute Tasks ]        <-- (Skills: executing-single-plan-task / execute-all-supervised)
         │
         ▼
[ Release / PR ]
         │
         ▼
[ Generate Changelog ]   <-- (Skill: changelog-generator)
```
