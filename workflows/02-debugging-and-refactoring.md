# Debugging & Refactoring Workflow

This flow outlines the steps taken to identify, root-cause, and resolve bugs, or simplify code.

```text
[ Bug Reported / Code Smell Identified ]
                 │
                 ▼
     [ Reproduce & Isolate ]
                 │
                 ▼
         [ Debugging ]            <-- (Skill: debugging)
                 │
                 ▼
    ┌────────────┴────────────┐
    ▼                         ▼
[ Fix Bug ]            [ Simplify Code ]   <-- (Skill: code-simplifier)
    │                         │
    └────────────┬────────────┘
                 ▼
        [ Validate / QA ]         <-- (Skill: qa-execution)
                 │
                 ▼
       [ Document Issue ]         <-- (Skill: troubleshooting-writer)
```
