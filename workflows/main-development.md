# Main Development Workflow

From a fresh idea all the way to a closed Jira ticket.

## Happy Path

```
┌──────────────────────────────┐
│      write-requirements      │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│       design-discovery       │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│          plan-prep           │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│      architect-solution      │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│        plan-implement        │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│         execute-all          │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│           release            │
└──────────────────────────────┘
```

## Alternate Paths

### Start from a Jira backlog item

```
┌──────────────────────────────┐
│          jira-shred          │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│      write-requirements      │
└──────────────────────────────┘
        (continue happy path)
```

### No design work needed (backend / infra only)

```
┌──────────────────────────────┐
│      write-requirements      │
└──────────────┬───────────────┘
               │   (skip design-discovery)
               ▼
┌──────────────────────────────┐
│          plan-prep           │
└──────────────────────────────┘
        (continue happy path)
```

### No architecture decisions needed

```
┌──────────────────────────────┐
│          plan-prep           │
└──────────────┬───────────────┘
               │   (skip architect-solution)
               ▼
┌──────────────────────────────┐
│        plan-implement        │
└──────────────────────────────┘
        (continue happy path)
```

### Single task instead of full plan

```

               │
               ▼
```

```
               ▼
```

```
               │
               ▼
┌──────────────────────────────┐
```

```
               │
               ▼

               ▼
```

## Inside `release` (for reference)

```
┌──────────────────────────────┐
│           release            │
└──────────────┬───────────────┘
               │
               ├──► product-guide-writer
               ├──► commit-git
               ├──► write-changelog
               ├──► push
               ├──► deploy staging
               ├──► deploy prod
               └──► close jira ticket
```
